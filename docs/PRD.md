# Auto Write PRD

## Product Goal

Auto Write는 Apple 기기에서 녹음한 회의를 자동으로 전사, 요약, 분류, 정리, 공유하는 AI 회의록 앱이다. 개인 개발/운영 단계의 비용은 0원을 유지하며, 오픈소스와 로컬/자체호스팅 가능한 구성만 사용한다.

## MVP Scope

- 회의 녹음 파일 업로드
- 비동기 처리 상태 추적
- STT 전사 세그먼트 저장
- 요약, 결정사항, 액션아이템 자동 생성
- 회의 유형/일자/태그 기반 목록 관리
- 공유용 Markdown/PDF 내보내기
- 링크 기반 읽기 전용 공유
- iPhone/iPad/Mac 대응 SwiftUI 클라이언트 골격

## Post-MVP Scope

- 화자 분리 고도화
- 캘린더 기반 회의 자동 인식
- 팀 워크스페이스와 멤버 권한
- SSO, 감사 로그, 기업용 보관 정책
- 오프라인 우선 동기화
- 온디바이스 LLM 또는 전용 로컬 모델 관리 UI

## Primary User Flow

1. 사용자가 회의 녹음을 시작한다.
2. 회의 종료 후 제목을 입력하고 업로드한다.
3. 서버가 파일을 저장하고 큐에 작업을 등록한다.
4. 워커가 전사, 요약, 분류, 액션아이템 추출을 수행한다.
5. 사용자는 회의 목록에서 상태를 확인하고 상세 회의록을 본다.
6. 필요한 회의록만 링크 또는 Markdown/PDF로 공유한다.

## Success Criteria

- 10분 이하 테스트 음성은 업로드 후 완료 상태까지 자동 진행된다.
- 완료된 회의는 요약/결정/할 일/전사 전문을 API로 조회할 수 있다.
- 회의 목록은 유형, 날짜, 검색어 기준으로 필터링된다.
- 공유 링크는 만료일과 권한을 가진다.
- Swagger UI에서 주요 API를 테스트할 수 있다.

## Non-Goals

- 유료 STT/LLM API 의존
- 초기 버전에서 Android/Web 동시 출시
- 초기 버전에서 다중 사용자 실시간 공동 편집
- 기업용 규정 준수 인증
